# Care wording inventory

Application source inventory after removing the “Care team resources” badge and changing the chatbot opening to “verified guides.” The later approved changes are recorded separately below. Each row quotes a distinct source string; `${…}` marks runtime text and repeated locations share a row. Whitespace is normalized, so text split across JSX elements may appear as adjacent fragments.

This covers website UI, accessibility labels/tooltips, frontend/server errors, notifications and seeded/source-title copy. Email-only copy is marked separately by its location. Live database/user-authored content and text inside uploaded PDFs are not exhaustively enumerable from the application source. Code identifiers, comments and obsolete migration history are excluded.

## Subsequent approved replacements

The tables below preserve the wording reviewed in the original inventory. Since that review, the following additional replacements have been applied to the website:

- “institutional care guides” → “institutional guides” in page descriptions.
- “Verified Care Knowledge” → “Verified Knowledge” in the chatbot tooltip.
- “Care Sources” → “Sources” in chatbot responses.

Other terms remain unchanged pending user review.
